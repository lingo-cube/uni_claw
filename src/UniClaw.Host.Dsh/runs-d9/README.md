# 历史运行证据路径

本目录保存2026-10-07的历史运行产物，不属于Host源码，也不是当前验收结果。现有164个受版本管理文件的原路径及SHA-256已记录在[本轮清单](../../../evidence/eng-opt-001/historical-runtime-paths.json)。

这些路径被历史Change和冻结证据清单引用，因此本轮保留原路径和内容。不要把新运行继续写入这里，也不要批量删除或按当前结果改写旧事实。

新运行通过Host的`--runs`显式选择输出根；需保留的验收输出放入对应`evidence/<change>/<run>/`，普通本地运行使用源码目录之外的绝对输出路径。入口与参数见[Host导航](../README.md)。

若后续搬迁，须新增旧路径→新路径的哈希映射和复现入口；不能改写旧manifest来假装原路径未变。仅搬文件且不保留路径别名，会使旧命令和旧清单无法按字面直接读取。
