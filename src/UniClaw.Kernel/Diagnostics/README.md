# Diagnostics 代码索引（非权威度量 · LAT-001 词表）

Product Runtime 派生路径的**观察阶段度量**：每阶段的耗时/计数词汇与
聚合。非权威——不产生 judgment、不回流决策、不改主流程行为。

## 代码归属

| 文件 | 职责 |
|---|---|
| `RuntimeStageMetrics.cs` | 阶段词表（LAT-001）与度量聚合 |

## 变更规则

观察度量语义进本目录；度量**定义**变更（阶段增删、口径变化）须同步
LAT-001 词表记录。任何以度量数值直接驱动控制/保障决策的连线不进本
维度（那是 Control/Assurance 用自己事实源做的判断）。
