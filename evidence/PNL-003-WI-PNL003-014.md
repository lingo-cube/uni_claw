# PNL-003 / WI-PNL003-014 — 导航任务卡去重证据

## 做了什么

修复 renderer 导航投影，使 project nested task card 与 flat task list 不会把同一任务展示两次。

## 原来的问题

DSH 的 `navigation.projects` 已带有任务实例，`navigation.taskInstances` 又带同一 ProductSession；共享 HTML renderer 顺序渲染两者，左侧出现重复任务卡。数据层没有重复，问题发生在最终呈现层。

## 这次修改

- `renderWorkspaceHtml` 先渲染项目内任务，再用 `productSessionId` 优先、`id` 兜底过滤 flat task cards。
- 项目无嵌套任务时，flat task list 仍渲染。
- 无 ProductSessionId 的未关联任务不被静默过滤，继续保留 `uncorrelated` 标识。
- 仅修改 `render-workspace-html.js` 与对应 renderer 测试，没有改 View Model、Query Core、Host adapter 或 DSH API。

Standalone 与 DSH 入口现在共享同一套无重复导航呈现；数据与 Host 边界没有被 renderer 修复绕开。
