# Evidence — WI-PNL003-009 Host-neutral App Wrapper

## Scope

新增 `web/uniclaw-workspace/src/app/create-workspace-app.js` 与测试。App wrapper 负责装配 Query Core、Controller、View Model、Renderer，通过注入 `mount` 输出 `{html, viewModel, state}`，不依赖 DOM、React、DSH 或 Host transport。

## Acceptance → evidence

| Acceptance | Evidence |
|---|---|
| 入口装配 | `createWorkspaceApp` 支持 Query Core、Controller、Renderer、mount 和 viewOptions 注入，并暴露 start/stop/getController/getState/getError。 |
| 生命周期 | 测试覆盖重复 start 复用同一 Promise、stop 取消订阅、stop→start 重新挂载，以及 in-flight stop 后旧响应不再 mount。 |
| 同一快照 | mount 接收 state、viewModel、html；任务选择测试验证 state 与 View Model 使用同一个 ProductSessionId。 |
| 错误可观察 | Query 错误保留在 Controller state；renderer/mount 错误通过 start rejection 和 getError 暴露。 |
| Host 解耦 | 精确扫描未发现 DOM、React、fetch、fs/path、DSH 或 Host globals。 |
