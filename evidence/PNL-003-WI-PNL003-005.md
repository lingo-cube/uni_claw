# Evidence — WI-PNL003-005 Standalone Fixture Adapter

## Scope

新增 `web/uniclaw-workspace/src/adapters/standalone-fixture.js` 和对应测试。它只提供内存 fixture 的五类 capability，复用既有 `WorkspaceQueryCore`，没有引入 HTTP、认证、文件系统或 UI。

## Acceptance → evidence

| Acceptance | Evidence |
|---|---|
| 五类 capability 与统一 envelope | factory 返回 Task/Session/Trace/Evidence/Detail 五类 capability；实际 `TaskQuery.listProjects` 响应通过 capability schema 校验。 |
| 完整主流程 | `runs the complete read-only flow through the shared Query Core` 覆盖项目、任务、session、timeline、三类 trace、evidence、detail。 |
| 来源替换与幂等 | `is source-replaceable, repeatable, and does not mutate the fixture` 验证替换实现、重复读取和深拷贝隔离。 |
| 失败可观察 | `returns structured missing, permission, and stale errors` 覆盖 `not-found`、`permission-denied`、`stale`，错误没有折叠为空数据。 |
| DSH 解耦 | 精确静态扫描只检查 import、Host global、fetch、fs/path、Typert 和 sessionController，结果为 `standalone-dependency-scan-clean`。 |
