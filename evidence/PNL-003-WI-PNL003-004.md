# Evidence — WI-PNL003-004 Capability Response Contract

## Scope

本项闭合 `schemas/workspace/capability.schema.json` 的响应 envelope。契约现在同时声明 capability metadata、`data`/`error`、snapshot metadata、分页 cursor 和局部错误；没有修改 Query Core、DSH Adapter、DSH 旧 API 或 Product Runtime。

## Acceptance → evidence

| Acceptance | Evidence |
|---|---|
| 成功/失败响应可校验 | `ok=true` 要求 `data` 且禁止 `error`；`ok=false` 要求结构化 `error` 且禁止 `data`。 |
| 快照元数据 | `snapshotId`、`revision`、`observedAt` 使用 `anyOf` 至少一项；允许 adapter 同时带多个来源时间/版本字段。 |
| 扩展与 fail-closed | `nextCursor`、`errors`、`productSessionId` 有明确类型；未知关键字段反例被 `additionalProperties: false` 拒绝。 |
| 正反例 | 新增 capability response success/failure 正例，以及 missing-error/unknown-field 反例；validator 输出 JSON path 诊断。 |
