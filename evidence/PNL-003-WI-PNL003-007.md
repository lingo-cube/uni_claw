# Evidence — WI-PNL003-007 Shared Frontend View Model

## Scope

新增 `web/uniclaw-workspace/src/features/workspace-view-model.js` 与测试。它把 Controller state 转成 renderer-neutral 的导航、任务头、Uni-Agent 主线、Trace/Evidence/Metadata pane、Detail actions 和 notices，不执行读取，也不依赖 React、DOM、CSS、DSH 或 Host。

## Acceptance → evidence

| Acceptance | Evidence |
|---|---|
| 信息层级 | `conversationTimeline` 固定 request/decision/result 三组；主卡片只保留摘要，原始记录保存在 `raw`/`detailRef`。 |
| 来源分组 | `tracePane.groups` 按 source 分组，并保留 authority、correlationId、detailRef。 |
| 关联边界 | 未关联任务保留 `correlationStatus: uncorrelated` 且没有 productSessionId；未关联 Evidence 即使带 detailRef 也禁用 Detail action。 |
| 局部失败 | loading、partial、stale、permission-denied、not-found、uncorrelated 保留在 pane/notices，整体状态不伪装为空成功。 |
| 输入不可变 | 完整投影测试比较输入前后序列化内容，View Model 使用深拷贝读取。 |
| Host 解耦 | 精确静态扫描未发现 React、DOM、CSS、fetch、fs/path、DSH 或 Host global 依赖。 |
