# Evidence — WI-PNL003-003 DSH Host Adapter

## Scope

Luna 在 `dsh/uniclaw-task-workbench/src/workspace-capabilities.js` 增加 DSH Host Adapter，并在 `dsh/uniclaw-task-workbench/tests/workspace-capabilities.test.mjs` 增加确定性测试。Adapter 只消费注入的 `panel` 与显式 `resolveProductSession`，没有改动共享 Query Core、Workspace schema、DSH 旧 HTTP/typert API 或 Product Runtime。

## Acceptance → evidence

| Acceptance | Evidence |
|---|---|
| 五类只读 capability | `createDshWorkspaceCapabilities` 返回 `TaskQuery`、`SessionQuery`、`TraceQuery`、`EvidenceQuery`、`DetailQuery`；成功/失败 envelope 均带版本、requestId 和 `revision` 或 `observedAt`。 |
| DSH session 不升级为 ProductSession | 测试 `missing mapping is uncorrelated and never upgrades a DSH session` 验证 resolver 未返回显式映射时不调用 panel。 |
| 现有 workbench 映射 | Session 投影保留 conversation、metadata、task、instance、`dshTrace`、`uniflowTrace`、`uniclawTrace`、evidence；Trace 输出保留 `dsh`、`uniflow`、`uniclaw` 来源。 |
| 局部失败可观察 | panel error、malformed workspace/session payload 和 resolver 异常均返回结构化 `QueryError`，不会折叠为空数据或 reject。 |
| 受控详情引用 | Detail 只调用注入的 `panel.artifact`；绝对路径、协议 URL、路径 traversal 和控制字符被拒绝。 |
| 依赖与边界 | 静态扫描未发现 React、DOM、fetch、node:fs、node:path、Typert、sessionController 或 DSH global 依赖。 |
