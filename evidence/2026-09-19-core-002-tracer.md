- Level: DETERMINISTIC

## 实施范围

- 新增 `src/UniClaw.Core/UniClaw.Core.csproj`，无 ProjectReference。
- 新增候选语义记录：Clause、Segment、EvidenceRecord、Slice、Claim、Effect、Attempt、TargetBinding。
- 新增纯语义不变量：历史绑定依据稳定性、canonical binding 才可投递、Unknown 不产生 World Result、投递完成/失败与 Unknown 区分。
- 新增 `tests/UniClaw.Core.Tests`，不依赖 Kernel、UI、设备 SDK 或 Harness。
- 将 Core 和 Core.Tests 加入现有 solution；未添加 Kernel→Core 迁移引用。

## 验证命令

```text
dotnet test tests/UniClaw.Core.Tests/UniClaw.Core.Tests.csproj --no-restore --logger 'console;verbosity=minimal'
```

## 实际结果

```text
通过: 3
失败: 0
跳过: 0
```

覆盖：

1. 滚动形成多个重叠 Slice，旧 Slice 不被新 Slice 改写；
2. TargetBinding 固定到建立绑定时的 Slice，当前 Slice 改变不会自动漂移；
3. Attempt 时间独立于 Slice 观察时间；
4. Unknown 不产生 World Result，也不能作为可投递 Binding；
5. Stale、Ambiguous、Unauthorized、Unverified 与 Canonical 保持不同状态。
