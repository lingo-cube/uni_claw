# Evidence — WI-PNL003-008 Shared Frontend HTML Renderer

## Scope

新增 `web/uniclaw-workspace/src/ui/render-workspace-html.js`、`src/styles/workspace.css` 和测试。Renderer 只消费 View Model，输出语义 HTML；样式独立维护，未引入 React、DOM、DSH 或 Host 挂载。

## Acceptance → evidence

| Acceptance | Evidence |
|---|---|
| 语义区域 | 测试覆盖 navigation、task header、conversation、Trace、Evidence、Metadata、Detail drawer 和 notices。 |
| Uni-Agent 主线 | request/decision/result 三组通过 View Model 渲染；主卡片只显示 summary/source，不直接铺 raw。 |
| Detail 安全边界 | 可用详情使用 `data-detail-ref`；permission-denied、not-found、uncorrelated 渲染为 disabled，不携带 action。 |
| HTML 安全 | 文本、属性和 detail ref 统一经过 escape，script/img 注入测试通过。 |
| 样式分离 | `workspace.css` 独立包含 token、布局、卡片、timeline、pane、状态色和响应式规则；renderer 无大段 inline style。 |
