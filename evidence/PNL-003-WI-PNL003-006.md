# Evidence — WI-PNL003-006 Shared Frontend 功能状态层

## Scope

新增 `web/uniclaw-workspace/src/features/workspace-controller.js` 与测试。Controller 只消费 `WorkspaceQueryCore` 的读模型，把项目、任务选择、Uni-Agent timeline、来源分类 trace/evidence、detail lazy load、刷新和局部错误编排成 renderer-neutral 状态；没有引入 React、DOM、CSS 或 DSH。

## Acceptance → evidence

| Acceptance | Evidence |
|---|---|
| 主流程状态 | `runs project to task to read-model detail flow` 覆盖项目→TaskInstance→session→timeline→trace/evidence→detail。 |
| 局部失败可见 | `preserves local errors and lazy detail failures` 以及项目任务列表的 loading/partial/error 测试保留错误，不变成空成功。 |
| ProductSession identity | Controller 的 session/timeline/trace/evidence/detail action 都通过当前 `productSessionId`；detail request 传身份但不修改 DetailRef。 |
| 旧响应隔离 | 项目切换、任务切换和延迟 detail 测试证明旧响应不会覆盖当前选择。 |
| renderer/Host 解耦 | 精确扫描未发现 React、DOM、CSS、fetch、fs/path、DSH 或 Host globals。 |
