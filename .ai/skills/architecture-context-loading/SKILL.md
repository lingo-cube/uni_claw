# Architecture Context Loading

Use this process to load only the context required for a task.

1. **Level 0 — Authority:** load the governing constitution and architecture index.
2. **Level 1 — Architecture Baseline:** load the applicable architecture baseline.
3. **Level 2 — Protocol / Domain Contract:** load contracts relevant to the task.
4. **Level 3 — Current State Projection:** load the current project state.
5. **Level 4 — Active Tasks:** load the work items and gates in scope.
6. **Level 5 — Historical Evidence:** retrieve history only when evidence is needed.

Load authority first, then current state, then active work. Do not default to all historical decisions, substitute historical documents for current state, or infer importance from file count.
