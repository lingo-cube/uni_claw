# trace-analyzer 记忆索引

本目录是 trace-analyzer agent 的自建记忆（git 跟踪）。每次任务开始加载，任务结束沉淀，刷新检查时精简。

| 文件 | 内容 | 更新频率 |
|------|------|----------|
| [knowledge.md](knowledge.md) | 分层知识蒸馏（L1–L4 精简版） | 刷新检查时（来源文档更新 → 重读重精简） |
| [lessons.md](lessons.md) | 案例经验（诊断中验证过的事实/方法/局限） | 每次任务结束追加 |

## 刷新检查规则

- 每次任务开始：比对本目录文件 mtime 与来源文档 mtime（`git log -1 --format=%ci <文档>` 更可靠）
- 有文档比记忆新 → 重读该层 → 重精简对应条目（合并同类、删过时）
- 记忆是分层知识的**精简蒸馏**，不是替代——先加载层文档的硬约束不变
