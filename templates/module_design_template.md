## 测试执行标准

### 运行测试
```bash
# 运行所有测试
python src/{module}/run_tests.py

# 运行特定测试
python -m pytest test/test_{feature}.py -v

# 生成覆盖率报告
python src/{module}/run_tests.py --coverage
```

### 测试报告解读
- **报告位置**: `src/{module}/test/test_report.json`
- **关键字段**:
  - `status`: "passed" 或 "failed"
  - `summary`: 测试统计
  - `ai_interpretation`: AI可读的结果描述

### 任务完成条件
只有满足以下条件才能标记任务完成：
1. ✅ 测试状态为 `"passed"`
2. ✅ 没有failed或error的测试
3. ✅ 测试覆盖率不低于基线
4. ✅ 关键功能测试全部通过

---

## 质量门禁

### 阻止任务完成的条件
- ❌ 测试失败数 > 0
- ❌ 测试错误数 > 0
- ❌ 覆盖率下降 > 5%
- ❌ 关键测试失败

### 警告但不阻止的条件
- ⚠️ 覆盖率轻微下降 (< 2%)
- ⚠️ 新增代码缺少测试
- ⚠️ 测试命名不规范
