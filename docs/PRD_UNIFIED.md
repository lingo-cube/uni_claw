# 1. 产品概述

## 1.1 产品定位

**Uni-Claw** 是一个 AI 驱动的移动 UI 自动化遍历测试框架，专注于车机菜单系统的自动化测试与验证。

**核心能力**：
- **图驱动遍历** - 基于有向无环图的声明式遍历计划
- **智能状态机** - 三层状态机控制遍历执行
- **仿真测试系统** - 无需真实设备的完整测试环境
- **AI 增强决策** - 可选的 AI 辅助决策能力（规划中）
- **全链路可观测** - 完整的 Trace 记录与可视化

## 1.2 核心价值

| 价值维度 | 描述 |
|---------|------|
| **效率提升** | 自动化遍历替代手工测试，10 倍效率提升 |
| **成本降低** | 仿真测试零运营成本，AI 可选按需使用 |
| **质量保障** | 确定性断言 + 可视化报告，快速定位问题 |
| **开发友好** - CI 优先架构，秒级反馈，易于集成 |

## 1.3 目标用户

- **测试工程师** - 编写和维护自动化测试用例
- **开发人员** - 本地验证功能，快速调试
- **QA 团队** - 回归测试，质量门禁
- **产品经理** - 可视化遍历结果，验证功能

# 3. 核心功能模块

## 3.1 图模型 (Graph Model)

### 3.1.1 统一节点结构

```python
@dataclass
class TraversalNode:
    node_id: str                    # 唯一标识
    name: str                       # 显示名称
    node_type: NodeType             # container/leaf_*
    operation: Operation            # 具体动作
    precondition: Precondition       # 前置条件
    children_strategy: ChildrenStrategy  # 子节点生成策略
    error_policy: ErrorPolicy       # 错误处理
```

### 3.1.2 节点类型

| 类型 | 用途 | 示例 |
|------|------|------|
| `container` | 容器节点，可包含子节点 | 设置主页面 |
| `leaf_switch` | 开关类叶子节点 | 自动亮度开关 |
| `leaf_slider` | 滑块类叶子节点 | 音量滑块 |
| `leaf_action` | 动作类叶子节点 | 返回按钮 |
| `leaf_info` | 信息类叶子节点 | 版本信息 |

### 3.1.3 子节点策略

| 策略 | 描述 | 使用场景 |
|------|------|----------|
| `STATIC` | 静态子节点列表 | 精确控制路径 |
| `DYNAMIC_MATCH` | 基于模板动态匹配 | 自动探索未知菜单 |
| `NONE` | 无子节点 | 叶子节点 |

## 3.2 状态机 (State Machine)

### 3.2.1 三层状态机架构

```
┌─────────────────────────────────────────────────────────────┐
│                    三层状态机                                │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  全局状态机 (Global FSM)                                    │
│  ┌──────────────────────────────────────────────────┐       │
│  │ IDLE → INITIALIZING → TRAVERSING → COMPLETED    │       │
│  │        ↓                    ↓                   │       │
│  │    ERROR ←─────────── PAUSED                   │       │
│  └──────────────────────────────────────────────────┘       │
│                                                              │
│  遍历状态机 (Traversal FSM)                                 │
│  ┌──────────────────────────────────────────────────┐       │
│  │ NODE_SELECT → PRECONDITION → EXECUTE            │       │
│  │     ↑              ↓         ↓                  │       │
│  │     └────────────←VERIFY ← BRANCH               │       │
│  └──────────────────────────────────────────────────┘       │
│                                                              │
│  节点栈 (Node Stack)                                        │
│  ┌──────────────────────────────────────────────────┐       │
│  │ [root] → [Settings] → [Display] → ...            │       │
│  └──────────────────────────────────────────────────┘       │
└─────────────────────────────────────────────────────────────┘
```

### 3.2.2 全局状态

| 状态 | 描述 | 进入条件 |
|------|------|----------|
| `IDLE` | 空闲 | 初始状态 |
| `INITIALIZING` | 初始化中 | 开始新遍历 |
| `TRAVERSING` | 遍历中 | 执行节点操作 |
| `PAUSED` | 暂停 | 用户暂停或等待 |
| `ERROR` | 错误状态 | 发生异常 |
| `RECOVERING` | 恢复中 | 异常恢复流程 |
| `COMPLETED` | 完成 | 遍历正常结束 |
| `TERMINATED` | 终止 | 强制终止 |

# 5. API 设计

## 5.1 核心执行 API

```python
# 图遍历执行
engine = GraphTraversalEngine(vision_service, action_executor)
result = engine.run(traversal_plan)

# 仿真测试
runner = SimulationRunner(virtual_pages, plan)
result = runner.run()

# 自然语言 API (规划中)
result = AIExecutor.run("遍历设置菜单的所有选项")
```

## 5.2 测试 API

```python
# 断言引擎
asserter = TraceAsserter(expected)
asserter.assert_trace(actual_trace)

# CLI 工具
simtest run tests/simulation/fixtures/test_case.json
simtest verify --trace trace.jsonl --expected expected.json
```
