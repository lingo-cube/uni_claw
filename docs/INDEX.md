## Project Context

Uni-Claw is a **modular, testable mobile application UI automation traversal framework** with the following key characteristics:

- **Core Functionality**: Intelligent app interface traversal using AI vision analysis and ADB control
- **Tech Stack**: Python 3.10+, ADB, DeepSeek/Anthropic AI
- **Architecture Style**: Interface-driven, dependency injection, event-driven
- **V6 Additions**: Simulator, state machine extensions, visualizable traces

### Key Design Principles

1. **Interface-Driven Design** - Core components use abstract interfaces
2. **Dependency Injection** - Improves testability
3. **State Separation** - State management independent of business logic
4. **Event-Driven** - Real-time traversal events
5. **Observability-First** - Built-in tracing, metrics, and logging
6. **Simulation-First** (V6) - Test verification capabilities without devices

### Core Module Quick Reference

| Module | Responsibility | Key Files |
|--------|----------------|-----------|
| **AI Service** | AI strategy decisions | `src/ai/` |
| **Traversal Engine** | Core traversal logic | `src/traversal/` |
| **Graph Traversal Engine** (V6) | Graph-based traversal execution | `src/traversal/graph_engine.py` |
| **Simulation Simulator** (V6) | Offline testing and verification | `src/simulation/` |
| **State Management** | State persistence | `src/state/`, `src/state_machine/` |
| **Exception Handling** | Exception chain processing | `src/exception/` |
| **Observability** | Tracing/metrics/logging | `src/trace/`, `src/analysis/` |
| **Graph Model** (V6) | Declarative traversal plans | `src/graph/` |
