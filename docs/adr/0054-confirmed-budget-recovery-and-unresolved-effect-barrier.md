# ADR-0054：恢复已确认消耗，未决Effect阻断继续

状态：accepted（2026-10-22，WORLD-UNCERTAINTY-001第一轮Q2；用户回复“按推荐”）。这是恢复范围的设计决定，非产品实施或完整恢复能力已通过验收的声明。

ADR-0050将崩溃后的额度恢复留待真实恢复场景裁决。WORLD-UNCERTAINTY-001选择首期恢复同一Run已确认的消耗与续授，避免已消耗额度在重启后重新可用；在途Effect无法可靠对账时阻断该Run继续并升级处理，不自动重发。暂不承诺恢复完整执行现场并自动继续，避免将预算恢复扩大为无法证明安全的在途动作恢复。

本决定仅补充ADR-0050的恢复范围，保留ADR-0052的资源策略、P25续授、步数与咨询轮次独立、Contract不变和不新增canonical Run State转移的边界。可靠执行源仍归Effect Boundary（ADR-0023），非幂等动作的dispatch前安全规则仍按ADR-0017；预算记录不能替代投递或效果事实。持久数量、原有消耗口径的恢复映射、幂等关联、异常记录处置及具体恢复协议仍在设计中，不能从trace、日志条数或缺失记录推断零消耗、成功投递或执行许可。

取舍：首期接受在途不明时无法继续执行，换取不猜测投递、不扩大授权。未选择“仅说明易失而不恢复已确认账目”，也未选择“同时承诺完整跨进程执行现场恢复”。未解决的账目或执行事实必须显式暴露，不得用初始额度或旧定位静默填补。
