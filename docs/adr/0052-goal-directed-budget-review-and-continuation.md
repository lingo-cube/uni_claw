# ADR-0052：目标推进驱动的明确续额复核与持续执行

状态：accepted（2026-10-18；Owner在整体提案交付后授权指定Leader/Worker实施，决定见RUNTIME-OVERVIEW-001 D1-D16与handoff.md）。实现及验收状态由该Change维护；本状态不表示运行执法已完成替换。

当前固定累计256步/320轮没有本次任务规模标定依据，而单凭动作计数、停滞计数或Agent省略可选续额字段，也不能证明继续没有价值。采用Runtime按资源阈值主动触发明确复核、UniAgent结合目标及连续overview判断与提案、Runtime按规则校验记录的分工；正常推进且下一段有依据时可逐笔续授，偏差/重复无成果/证据不足时加强复核。

## 对既有决定的部分替代

- 替代ADR-0050§1以累计有限policy HardCap作为必需终止测度的要求，以及ADR-0051§3中依赖该要求的咨询总数限制；不取消咨询与动作消耗记账、P25相关性或明确资源授权边界。仍可执行有任务/授权依据的有限资源限制，但不以未经标定的固定步数作为通用停止理由。
- 保留ADR-0050的P25续授通道、步数/轮次独立、Agent与规则共同决定、续额不是Contract mutation及不新增canonical Run State transition。
- 本ADR实施时同步核心规则与正式装配、Host提前停止出口、协议及验证；不得仅在adapter绕过校验。ADR-0050/0051保持accepted，其相应要求由本ADR部分替代；未替代部分继续有效。

单笔默认续额按本Run初始获批额度的20%分别向上取整，允许按下一段需求说明调整理由，不按累计额度复利增长。复核漏答最多一次计入资源的纠正，仍未完成则不授额；授额、纠正或重规划不重置历史、累计消耗或失败事实。资源阈值是复核时机，计数异常是调查信号，均不直接成为目标方向结论。

## 代价与保留边界

放弃没有任务依据的固定步数停机保证，换取对长任务正常推进的支持。若另有明确、可计量的时间/费用等资源授权边界则执行；没有时不声称全局必然终止，语义复核也不是数学终止证明。无限重问、无依据自动续额、复用早期成果支持同路线空转均不允许；局部受阻继续其他可行分支，完成仍经既有Assurance/Outcome验证。

World Model继续独占世界实体/关系及图投影，任务进展、复核判断与预算记录不进入World Graph。overview为关联既有事实的只读消费视图，不成为新的事实、许可或完成权威。

RUNTIME-OVERVIEW-001已按本决定实现并关闭，调用链、确定性/现场四元组及局限见[evidence/runtime-overview-001/verification.md](../../evidence/runtime-overview-001/verification.md)。正式Settings配置开启目标推进策略；旧HardCap模式保留兼容，显式授权总顶仍执法。World导航与任务证明、预算判断保持分权，源码、协议/Prompt与生成物同Change同步。真实模型探针证明明确双维续额与导航图接通，但滚动覆盖及完成锚点未满足，不能将实施关闭等同Settings全遍历完成。
