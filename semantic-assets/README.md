# semantic-assets — Container Identity Semantic Evaluation Assets

Logical separation of Semantic evaluation corpora. Rule: **held-out data never
participates in tuning; tuning data never validates generalization.**

| Directory | Role | Mutability |
|---|---|---|
| `profiles/` | Frozen evaluation profiles (e.g. `BGE_SMALL_CONTAINER_IDENTITY_PROFILE_V1.json`) | IMMUTABLE once frozen; changes only via a new profile version |
| `tuning/` | The tuning/training corpus (canonical C# corpora used to design rules & thresholds) | Read-only reference; refits require a new gate |
| `heldout/` | Independent held-out validation corpus + benchmark reports | Corpus immutable per version; reports regenerated by benchmark runs. `ContainerIdentity-heldout-v1` is now **FORMER_HELDOUT** (regression/adversarial evidence source; see `heldout/MANIFEST.md`); future final qualification requires `heldout-v2` |
| `regression/` | Registry of historical failure families (references, not duplicate corpora) | Read-only |
| `adversarial/` | Registry of adversarial families (references, not duplicate corpora) | Read-only |

## Isolation rule (enforced)

- Held-out case ids never overlap tuning case ids.
- Held-out element fingerprints (text, perception type, switch state) never
  overlap tuning element fingerprints.
- No benchmark/tuning helper loads `heldout/`; no validation helper loads `tuning/`.
- Proof: `tests/Semantic/BenchmarkTests/HeldOutValidationTests.T1`.
