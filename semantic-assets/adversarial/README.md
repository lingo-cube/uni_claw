# Adversarial Families Registry (Reference)

Adversarial Container Identity probes demanded by the held-out gate
(safety-first): wrong container, visually similar container, text-overlap
container, structurally similar container, insufficient evidence, conflicting
previous identity, empty/near-empty semantic query.

See `semantic-assets/heldout/ContainerIdentity-heldout-v1.json` for the
concrete cases (F dimension per identity) and
`docs/benchmarks/bge-small-held-out-validation.md` for results.
