## Documentation Sync Checklist

When code changes affect module design:

- [ ] Review affected design docs in `docs/architecture/modules/`
- [ ] Update class/interface descriptions if changed
- [ ] Update dependency diagrams if changed
- [ ] Update version number and date
- [ ] Link to updated TESTING_STANDARDS.md if applicable

## Design vs Code Consistency Check

- [ ] Design document version matches implementation version

- [ ] Architecture diagrams reflect current structure
