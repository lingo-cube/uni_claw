## Phase 1: 基础类型区分（当前实现）

### 实现范围

#### 按钮类型
| 类型 | 说明 | 示例 |
|------|------|------|
| MENU_ITEM | 可点击的列表项 | 设置列表中的项目 |
| TAB | 标签页按钮 | 页面顶部的标签 |
| BACK_BUTTON | 返回按钮 | 左上角返回箭头 |
| SWITCH | 开关控件 | Wi-Fi 开关 |
| TOGGLE | 切换按钮 | 开/关状态按钮 |
| BUTTON | 普通按钮 | 确认、取消按钮 |
| ICON | 图标按钮 | 功能图标 |
| LINK | 链接 | 跳转链接 |
| TEXT | 纯文本 | 说明文字 |
| READONLY | 只读元素 | 不可点击的显示 |

#### 预期行为
| expected_action | 说明 | 等待时间 | 验证重点 |
|-----------------|------|----------|----------|
| NAVIGATE | 页面导航 | 1.0s | current_path 变化 |
| TOGGLE | 状态切换 | 0.3s | items/state 变化 |
| ACTION | 触发操作 | 0.5s | 弹窗/跳转 |
| NONE | 无响应 | 0.1s | 无变化 |

#### 交互方式
- **仅支持**: Tap（单击）
- **不支持**: 长按、滑动、拖拽等（Phase 2+）

### 支持的UI场景
✅ 点击菜单项进入子页面
✅ 点击标签页切换视图
✅ 点击开关切换状态
✅ 点击按钮触发操作
✅ 点击返回按钮导航
✅ 识别只读元素跳过

### 不支持的UI场景（后续阶段）
❌ 输入框输入文本 → Phase 2
❌ 长按弹出菜单 → Phase 2
❌ 滑动列表加载 → Phase 2
❌ 拖拽滑块调整 → Phase 3
❌ 下拉刷新 → Phase 2
❌ 缩放图片 → Phase 3

## Phase 2: 点击方式扩展（规划中）

### 新增内容

#### ClickType 枚举
```python
class ClickType(str, Enum):
    TAP = "tap"                # 单击
    LONG_PRESS = "long_press"  # 长按
    SWIPE = "swipe"            # 滑动
    DRAG = "drag"              # 拖拽
```

#### 新增按钮类型
| 类型 | 说明 | 交互方式 |
|------|------|----------|
| INPUT | 输入框 | TAP + 输入文本 |
| CONTEXT_MENU | 长按菜单项 | LONG_PRESS |
| SCROLLABLE_LIST | 可滑动列表 | SWIPE |
| PULL_REFRESH | 下拉刷新 | SWIPE (向下) |
| EXPANDABLE | 可展开项 | TAP / DOUBLE_TAP |

#### 新增 MenuItem 字段
```python
click_type: ClickType = ClickType.TAP
click_duration: float = 0.0        # 长按持续时间（秒）
drag_target: Optional[Coordinate] = None
swipe_direction: Optional[str] = None
swipe_distance: Optional[float] = None
```

#### 新增 ADB 方法
```python
def long_press(self, x: float, y: float, duration: float) -> None:
    """长按操作"""

def swipe(self, start_x: float, start_y: float, 
           end_x: float, end_y: float, duration: float) -> None:
    """滑动操作"""

def drag(self, start_x: float, start_y: float, 
         end_x: float, end_y: float, duration: float) -> None:
    """拖拽操作"""
```

### 支持的新场景
✅ 识别输入框并输入文本
✅ 长按弹出上下文菜单
✅ 滑动列表加载更多内容
✅ 下拉刷新页面内容
✅ 点击展开/折叠项

## Phase 3: 复杂交互支持（规划中）

### 新增内容

#### 新增按钮类型
| 类型 | 说明 | 交互方式 | 验证策略 |
|------|------|----------|----------|
| SLIDER | 滑块 | DRAG | 数值变化 |
| PROGRESS_BAR | 进度条 | TAP | 位置跳转 |
| PINCH_AREA | 可缩放区域 | PINCH | 缩放比例 |
| SEARCH_BOX | 搜索框 | TAP + INPUT + ENTER | 结果匹配 |
| PICKER | 选择器 | TAP + SELECT | 选中值 |

#### 新增 ClickType
```python
PINCH = "pinch"        # 缩放
ROTATE = "rotate"      # 旋转
MULTI_TOUCH = "multi_touch"  # 多点触控
```

#### 新增验证方法
```python
def _verify_slider_change(self, before, after) -> ClickResult:
    """验证滑块数值变化"""

def _verify_zoom_change(self, before, after) -> ClickResult:
    """验证缩放比例变化"""

def _verify_text_input(self, before, after, expected_text) -> ClickResult:
    """验证文本输入正确性"""
```

### 支持的新场景
✅ 拖拽滑块调整数值
✅ 滚动加载分页内容
✅ 缩放查看图片/地图
✅ 搜索输入并验证结果
✅ 选择器选择并验证

## 风险与缓解

### Phase 1 风险
| 风险 | 缓解措施 |
|------|----------|
| AI 类型识别不准 | 提供清晰示例 + 默认回退 |
| 等待时间设置不合理 | 可配置 + 实测调整 |
| 向后兼容性问题 | 默认值 + 测试 |

### Phase 2 风险
| 风险 | 缓解措施 |
|------|----------|
| ADB 手势支持差异 | 抽象接口 + Mock 测试 |
| 输入内容生成 | 模板化 + 用户配置 |
| 滑动参数调整 | 可配置 + 自适应 |

### Phase 3 风险
| 风险 | 缓解措施 |
|------|----------|
| 复杂手势实现复杂 | 分步实现 + 充分测试 |
| 验证策略复杂度 | 简化策略 + 容错处理 |
| 性能影响 | 性能测试 + 优化 |
