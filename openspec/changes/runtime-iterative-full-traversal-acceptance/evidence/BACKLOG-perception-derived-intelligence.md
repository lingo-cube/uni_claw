# 感知衍生智能 — 低优先级待办（leader 记录，2026-08-28）

> 来源：Phase 2.6 reentry 过程中连续 6 层感知不稳定修复链。
> 状态：待办，非当前任务。目的是从修复经验中提取"人类常识推理"模式，
> 未来作为 UniAgent 的智能输入。

## 核心洞察

人在滚动页面时，不需要每次滚动都看到完全一致的内容才能理解世界。
人用的是**推断**而不是**精确匹配**：

| 人会做的推断 | 当前 Runtime 的行为 | 差距 |
|---|---|---|
| "标题滚出去了只剩副标题 → 我滚过了这一行" | 归一化断链（签名不匹配） | 截断行可推断滚动方向和效果 |
| "这一行只看到一半 → 不拿它做判断" | 半行的错误文本进入匹配 | 边界行应降权或跳过 |
| "我看到了跟之前一样的行 → 我可能没滚动或滚回来了" | 子集窗口 → 断链 | 重复可见 = 滚动未生效的信号 |
| "连续几帧都有这个文字 → 它是稳定存在的" | 单帧判断 | 多帧一致性可提高置信度 |
| "这个文字每次都出现在同一行的下方 → 它是副标题不是标题" | 单帧角色判断 | 跨帧角色稳定性推断 |
| "类型偶尔变化但内容一样 → 是同一个东西" | 签名含类型 → 断链 | 类型不稳定时用内容做回退匹配 |

## 具体可挖掘的智能模式

### 1. 滚动效果推断（从截断推导）

截断行的出现 = 滚动确实生效了的证据：
```
观察到: 窗口首行文本变了（标题→副标题 或 不同行出现）
推断:   滚动生效了，方向向下，幅度约 1 行
用途:   调整下一步滚动幅度（当前是固定步长，可以自适应）
```

### 2. 视口边界意识

```
观察到: 某行的 bounds 只有正常高度的一部分（如 < 70%）
推断:   这行被视口截断，信息不完整
用途:   不拿截断行做决策依据，等下一帧完整可见时再确认
```

### 3. 跨帧稳定性投票

```
观察到: 同一位置的同一文本在 N 帧中出现了 M 次（M < N）
推断:   M/N 比例高 → 真实存在；比例低 → 检测噪声
用途:   检测置信度不足时，用多帧投票代替单帧判断
```

### 4. 角色稳定性推断

```
观察到: "Volume, vibration, Do Not Disturb" 总是出现在 "Sound & vibration" 下方
推断:   前者是后者的副标题（不是独立行）
用途:   跨帧学习行角色关系，减少每帧重新判断的错误
```

### 5. 子集窗口 = 滚动未生效信号

```
观察到: 新窗口是旧窗口的子集（没有新行）
推断:   滚动可能没生效（overscroll、bounce、到底了）
用途:   区分"需要继续滚动"和"已经到底了"和"滚动失败"
```

## 外挂智能的边界

以上推断都是 Runtime 内部可做的（不需要外部智能）。
但以下情况确实需要"外挂智能"（UniAgent / VLM advisory）：

| 情况 | 为什么 Runtime 做不了 | 外挂能做什么 |
|---|---|---|
| 确认"这个画面已经到底了" | Runtime 只能看到当前帧，无法知道列表总长度 | 结合历史知识判断"这大概是全部了" |
| 判断"这个文字是副标题还是独立行" | 需要语义理解（"Mobile, Wi-Fi, hotspot" 看起来像描述而不是标题） | 语义分析提供角色判断 |
| 决定"继续滚还是进入子页" | 需要目标意识（我到底要找什么） | 根据目标优先级做策略选择 |
| 从截断行恢复完整信息 | 需要领域知识（Settings 的行结构） | 提供先验知识辅助恢复 |
