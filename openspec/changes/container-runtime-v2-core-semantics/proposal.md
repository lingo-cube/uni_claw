## Why

Phase 2.6 produced 19 fresh real-device runs with 0 Completed and showed that blockers migrate across perception, occurrence identity, transition observability, current-location reconciliation, deep Unknown, and semantic interpretation. The previous ActiveContainerContext/typed-transition purchase is now frozen because it preserves an execution obligation when fresh evidence has already moved the physical world and cannot by itself express multi-entry relations, working unproven Containers, path-relative return, or evidence-only Fast/Slow correction.

## What Changes

- Freeze previous ContainerGraph-adjacent purchases as reconciliation inputs; old tasks, tests, implementation, and graduation statements do not establish Runtime V2 purchase or graduation.
- Introduce an evidence-backed, Run-local `ContainerGraph` world model with first-class trigger-bearing relations. The Graph is not a planner, action authority, current-world truth, immutable topology, or persistent memory.
- Introduce one thin Agent-owned `CurrentContainer` representing the current physical working location as `NodeRef + CurrentSlice + EntryContext`; pending execution/traversal obligations remain separate Agent/UniAgent evidence.
- Replace expectation-shaped transition authority with immutable `TransitionOccurrence` evidence. Transition completion does not wait for destination identity trust; abnormal/off-path occurrences do not automatically create normal Graph relations.
- Allow a working Container entity to exist before identity is proven and derive trust from revision-bound Fast/Slow assessments rather than a mutable trust FSM.
- Define path-relative return from current EntryContext. A node has no canonical parent, entry and return are separate occurrences/relations, and Back expectation is verified only by fresh observation.
- Reuse the existing Container local evidence owner for CurrentSlice and current-lifecycle LocalModel accumulation; bounds, text, ordinal, StableKey, geometry, and historical LocalModel entries remain evidence and cannot authorize dispatch.
- Separate coverage completeness from semantic resolution and subtree/Goal completion; deep Unknown does not alone negate proven frontier exhaustion.
- Add provider-neutral Fast resolution and Slow Advisor contracts. Fast/Slow return assessment evidence only; Slow begins Disabled/Shadow/Async Advisory and cannot mutate Runtime state, authorize actions, complete goals, or execute recovery.
- Compose the already purchased immutable reducer/Graph, Fast, Slow, correction, and checkpoint projections behind one stateless `ContainerRuntimeV2` lifecycle facade. The facade accepts and returns immutable state/evidence, adds no current/trust/correction owner, and leaves pure component/provider test seams directly callable.
- Deliver a revision-bound semantic-correction fact to one bounded Agent-owned consumer. The consumer may only correct attribution in the existing immutable obligation/progress evidence; it cannot create completion from observation, mutate GoalEvidence, dispatch action, or execute recovery. Checkpoint behavior, provider/backend purchase, cross-run Graph memory, and a transition FSM remain deferred.
- **BREAKING**: the existing rule that rejects every second occurrence of a semantic page identity across branches is replaced by relation/entry-context evidence. The same Destination node through different Source/Trigger relations is legal; loop prevention remains an Agent obligation policy and does not deny node existence.
- **BREAKING**: an accepted independent destination with unresolved semantic identity may establish an `INITIALIZED` working CurrentContainer instead of leaving current physical location on the prior Container or fabricating a trusted identity.

## Capabilities

### New Capabilities

- `runtime-v2-container-world-model`: Evidence-only ContainerGraph, working nodes, first-class trigger-bearing relations, graph recording/reading boundaries, and non-authority constraints.
- `runtime-v2-current-container-transition`: Thin CurrentContainer, EntryContext, immutable TransitionOccurrence, path-relative return, stale-revision rejection, and atomic current/evidence reconciliation.
- `runtime-v2-local-model-coverage`: CurrentSlice and node-lifecycle LocalModel correlation, fresh occurrence action grounding, frontier exhaustion, and coverage-versus-semantics separation.
- `runtime-v2-semantic-assessment`: Fast resolution, derived trust, Slow Disabled/Shadow/Async Advisory modes, assessment precedence/freshness, and no-authority boundaries.
- `runtime-v2-semantic-correction-boundary`: Revision-bound corrected semantic facts and the authority boundary where UniAgent recomputes obligations while Slow remains advisory.

### Modified Capabilities

- `open-world-traversal-identity-safety`: Replace run-global duplicate semantic-page rejection with relation/entry-context-aware evidence while retaining bounded Agent-owned loop prevention and GoalEvidence authority.
- `semantic-run-unexpected-navigation-reconciliation`: Accept an independent destination as a working current Container even when semantic identity remains unresolved, without treating it as goal success or action authority.

## Impact

- Primary Runtime surfaces: `src/UniClaw.Runtime/Agent/`, `Container/`, `Model/`, `World/`, existing Semantic evidence/fusion seams, and authority-free DriverHost projections.
- Existing symbols are reconciled before creation: `Container`, `ActiveContainerContext`, `ContainerTransition`, `Agent.ContainerReconciliation`, Container observation/history, completeness evidence, `_branchProgress`, `CompileExplorationLedgerView`, and Fast Semantic candidate/provider contracts.
- Tests cover deterministic and stateful async cases: multi-entry same-node relations, path-relative return, r5 expected/observed mismatch, working unproven destination, off-path occurrence, stale assessment, Fast/Slow conflict, coverage-complete with Unknown, and stale LocalModel bounds rejection.
- `AuthorityDelta = NONE`; `NET_NEW_MUTABLE_TRUTH = 0`. Graph, assessments, trust, checkpoint, and completeness projections remain evidence/derived views. Agent/UniAgent retains action, obligation, recovery, and Goal completion authority; Environment/Driver authority is unchanged.
- Human Gate status for this slice: `CONTAINER_RUNTIME_V2_AGENT_CORRECTION_CONSUMER_APPROVED_BOUNDED` and `CONTAINER_RUNTIME_V2_COMPOSITION_CONVERGENCE_REQUIRED`; neither decision authorizes graduation or migration of the old live current/execution path.
- The later Human decision `CONTAINER_RUNTIME_V2_LIVE_STATE_REPLACEMENT_APPROVED_BOUNDED` authorizes the staged production replacement of the old physical-current ownership at the existing Agent reconciliation seam. It does not authorize graduation, Goal/action/recovery changes, Slow production authority, provider/backend selection, or parallel live current state.
- No external model/provider, persistent Graph store, long-term memory, Global/Container/Recovery FSM, navigation planner, canonical parent, stable item ontology, or cross-run identity merge is purchased by this change.
