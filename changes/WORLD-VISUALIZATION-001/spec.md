# World可视化功能规格

## 用户目标
打开一个实际可用的界面，就能看懂World如何从观察建立认识、形成图与Slice、更新版本、参考已验证信息、发现错误并处理影响。展示图模型、Slice、分层版本与变化相互关联。它与Replay有复用基础：Replay侧重还原某时刻页面/操作，可视化还需解释World在多个观察和访问之间如何演变。具体既有界面/入口/实现栈由实施Leader核对当前仓库后选择，不另造无真实buyer的平台。

前置：WORLD-UNCERTAINTY-001核心交付完成、验收及提交推送。复用其真实模型和例子，不为看起来完整补造产品字段或把缺失依赖当无影响。核心实现与本功能分开验收和提交。

## 必须可查看的内容与联动

| 内容 | 用户能做什么 | 必须保留的含义 |
|---|---|---|
| 世界图 | 浏览Container、元素/对象及有据关系，选中节点/边，查看来源并定位相关页面 | 页面身份与路径参数区分；导航可返回同页、图可有环；没有关系不等于不存在关系 |
| 页面与Slice | 选中Container及版本，查看其Slice集合、各自范围、语义/控件/状态/布局，联动页面表达；选中控件可追溯对应对象 | Slice不可变只读；累计先经World采信；未知/空洞/冲突可见，多Slice不自动等于完整页 |
| 分层版本 | 沿时间/事件前进、后退、暂停或选择具体时点，区分Container身份、导航访问、观察/解释及World一致提交 | 同页多次访问不铸新身份；无导航也可更新；旧图重解释保留原采集时间；不同版本不能无标识拼成当前事实 |
| 变更比较 | 选择前后两个World版本或相应局部视图，看到新增/删除或撤销/修改/归属切换/来源与可信判断变化，点变化定位对象、Slice与来源 | 真正环境改变与认识纠错分开；不存在/未观察/历史失效含义分开；仅呈现正式模型可证明的信息 |
| 来源与因果 | 从变化看到观察、接纳、World判断、Slice/Agent实际消费及影响关系；选择事件联动图/页面/版本 | 时间、范围、已采信/候选/拒绝/未决/历史状态有清楚说明；未记录依赖明确未知，不补画伪因果 |
| 复用与纠正 | 看到历史参考何时先可读、何时采信当前稳定语义、哪些动态事实仍待证；第一版错时看到停止沿用、重判与实际影响核查 | 历史参考不是当前执行许可；仅记录/已消费/实际效果分开；未决/不可逆/terminal如实表达，不承诺自动撤销现实 |

界面采用易懂中文，状态不只靠颜色，选中/对比/历史模式有明确反馈。复杂图需可缩放/平移/筛选/聚焦及返回全图；足以读清对象关系，避免整屏线条无法定位。布局与信息层级服务上述流程理解，空数据/未知/部分资料/加载失败有可理解状态。

## 数据与架构

读取正式Owner派生的只读模型/投影，保持Ledger→World→Slice→现有消费的权威边界；采信/执行许可不在界面计算。真实生产数据、合格录制、受控仿真分别标识。回放期间对齐选定修订、访问、scope、capture及解释来源；支持原时点认识与更正后解释的明确切换，不覆盖旧快照。

先核实Replay当前读取、页面重建、坐标、布局、选择/时间线和对照资产，列复用/扩展/独立项及理由。产品功能不引用tests/程序集，不拷贝一套World；仅在真实展示buyer证明后增加必要的生产只读缝，模型/接口先独立审阅。外部效果状态取自原Owner可得记录，缺失时明确不可判断。不要为展示注入观察/真值、伪造Agent输入或执行动作。

## 使用前面例子的可视化验收

实施时将每个例子展开为真实初态、输入/事件顺序、关键中间帧、操作步骤、断言和截图/输出路径。复用核心实现的详细用例/仿真及可运行输入。对原MV01-18、RU01-08、CI01-12以及四类缺口、尝试/提醒、scope-id、Agent可见的全部主题给出展示覆盖映射；可合并场景，但每个主题有明确可见状态或合理不适用解释，不要求为每个主题另造页面。

| 验收例子 | 在界面上应能直接观察的行为 |
|---|---|
| /{device}/{detail}层级与局部页面 | 当前页只表达自身语义，上下文沿有据节点/边查看；路径变量不被误画成页面唯一身份 |
| 同页多次导航进入、每轮状态不同 | 相同Container、不同访问与观察/World版本可切换；状态变化有准确来源，返回边不被误画成非法环 |
| 多次滚动/局部观察形成页面 | Slice范围及布局联动、World采信前后、累计已知区域与空洞可见；无重叠/不兼容时不强行拼完整页 |
| 无导航的语义修正、旧图重解释及晚到结果 | 新World修订与原观察时间分开；迟到/拒绝依据可查看，当前图不被错误覆盖 |
| A页误归属纠正到B页 | 前后图、相关边、Slice和页面表达联动；旧证据与更正可追溯，旧视图保留 |
| 高置信稳定信息先参考再采信 | 慢模型未返回时参考已可看，对应充分后稳定语义沿用；当前位置/可见/开关状态未证部分单独显示 |
| 第一版错且后续操作/验证同源 | 显示原错依据、共同依赖、停止传播、影响对象/决定/动作与修正；仅记录与已执行效果清楚区分 |
| 未决效果、修复失败或terminal后纠正 | 原效果/终局不被新图覆盖，未决不变成功/失败，不表现为自动重试/旧Run复活，未完成核查可见 |
| 四类缺口与实际Agent可见性 | 可追溯当前缺口的对象/范围/依据、补证尝试/结果/解决情况及实际输入链；无资料时明确未知，不靠面板存在声称Agent已看到 |
| 同revision不同scope及版本比较 | 选中范围对应实际Slice身份和内容，不同scope不混淆；比较图、页面及来源一致，不以旧Slice授权当前消费 |

## 验证与完成

至少覆盖：实际数据链/契约校验、上述行为集成验证、运行界面的真实交互验证（选择/定位、图操作、时间推进、版本比较、Slice联动、来源追溯、未知/纠错状态），并检查常用桌面尺寸及窄窗口的可读性。使用仓库/Host可用浏览器工具，截图或视觉检查失败不能写视觉验收通过；静态HTML或示例截图不等于功能完成。
