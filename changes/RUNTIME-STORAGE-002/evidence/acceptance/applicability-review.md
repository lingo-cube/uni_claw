- 资源 v4 的基线只加速读取；旧 v2/v3 读取和严格恢复仍保留。新快照不授权删除增量或来源文件。

- World 的完整恢复要求完整前缀、hash/head 和跨 Run/Evidence/Resource 的位置关系。任何后续 baseline 都必须与这条 reader 并存，不能用“已有增量”或“没有 latest reader”降低 A5/A10。
