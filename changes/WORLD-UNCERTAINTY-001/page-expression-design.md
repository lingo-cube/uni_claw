# 同一Container的Slice集合如何形成可查看的页面表达

日期：2026-10-22。状态：设计稿；Q14 Accepted A、Q15 Accepted A、Q16 Accepted A。Authority NONE。仅设计与随行文档，不实施产品或运行模型/设备/测试；不冻结公共载荷或新接口。

## 已接受的目标

用户接受同一页面跨次观察的有据累计，并补充“一组Slice共同表达一个Container，然后Slice进行计算可以得到完整页面样子”。经范围澄清，Q16选择A：首期还原结构、控件语义、状态和布局，并能画出来查看；真实图标、字体、图片等外观还原不作为首期验收要求。

Container是世界实体，Slice是它在声明范围与来源版本下的局部只读表达。这里“计算”是对有依据的局部信息进行组合，得到该Container的页面表达；不因组合结果新铸Container，也不让图像/渲染成为世界真值。仍按节点与边维护实体及关联，Slice不自行修改所属关系。

跨观察累计与页面表达计算要有明确的先后关系：多次观察先经Ledger接纳与World的reconciliation，形成有来源的新WorldBelief revision；再从选定版本派生适合组合的局部Slice及必要只读上下文，计算页面表达。历史Slice可用来解释变化、辅助诊断，不能直接把不同历史时刻拼成未经World确认的当前事实。具体保留/解释历史依据的机制不得放宽当前occurrence执行引用的时效约束。

2026-10-23多轮补充：同一Container多次进入可以有不同现场状态，不能将每次变化都解释成前轮认错。历史认识的纠错明确目标观察、所属访问上下文、范围及新的World修订，按实际依赖重判受影响页面表达；同Container其他轮次的独立依据不被整页覆盖。原时点重建仍使用原修订，当前纠正后的历史解释明确标识新依据。旧轮覆盖、布局/位置、状态和缺口解决不自动成为新轮当前事实，见multi-visit-completeness.md的18类推演；尚无本轮产品验证。

```text
多次观察 → Evidence接纳 → World核对与累计 → Container的选定世界版本
                                            ↓
                                   局部Slice及必要上下文
                                            ↓
                                范围/布局对齐、重叠去重、冲突留痕
                                            ↓
                              可计算的页面表达 → 只读可视化
```

## 组合计算应做的事

1. 确认归属：只组合有依据属于目标Container的内容；同模板、同route、同文字不直接证明同一实体。Q15归属纠正先由World完成，再重算受影响页面。
2. 固定来源：组合使用明确的World版本、观察时间和处理规则。区分“此前见过”“当前已有依据仍成立”“当前可见”；历史观察中的控件不直接获得当前定位或执行权。
3. 统一布局：利用有依据的frame/区域/变换及已验证滚动关系，把局部内容放入可解释的页面布局。不能配准时保留多个局部及原因，不凭滚动手势距离或图片边缘猜唯一坐标。
4. 处理重叠：有充分对应依据时去重；相同文字/坐标不是全局身份。固定栏与滚动内容不能一起平移；嵌套滚动区缺明确归属时保持未知。
5. 处理变化与冲突：控件用途、状态或所属关系变化经World解释后使用；矛盾不足以解决就显示冲突。不得简单以最新字符串覆盖、累计次数投票，或删除旧依据掩盖纠错。
6. 表达覆盖：结果声明目标范围、已表达范围、空洞/未观测/未知/冲突。范围有充分覆盖依据时，才称该范围表达完整；多个Slice、列表当前为空或图中无待办不自动证明整页穷尽。
7. 渲染与解释：把结构、控件、状态、相对布局和未知区域画出来；可回溯本页组成及原观察依据。展示可见不等于当前可执行，绘图不回写World，不代替Assurance或Goal判断。

上述是行为与计算责任，不是已冻结字段、枚举或算法实现。数据由World派生；渲染只读消费；Simulation/Replay验证表达与来源，不成为生产World的事实源。需要新增公共模型或Interface时，先单列可审阅稿，不能把测试helper当成生产Owner。

## “完整”怎样判定

| 情形 | 应有结果 |
|---|---|
| 固定且明确范围，所有组成及关系都有兼容证据 | 可声明该范围结构/语义/状态/布局表达完整，并提供组成与来源 |
| 只观察到列表前几屏，终点/总范围未证 | 输出已知页面部分并标明未证范围，不把画布铺满视为完整 |
| 前后观察重叠且对应充分 | 合并可证明重复部分，保留来源关联；没有重复创建同一已确认内容 |
| 文本相同但不能判定是否同一项 | 不强行去重或认定连续身份，显示歧义 |
| 布局变化、嵌套滚动或缺少变换依据 | 结构/局部内容可保留；位置未知明确显示，不伪造完整长页 |
| 前半页状态在后半页观察前发生变化 | 由World判断仍可成立的内容；未证的旧状态保留历史或未知，不冒充同一时刻当前页 |
| A页归属后来正式纠正到B页 | 新版本及受影响页面表达更新，错误当前关联不继续使用，旧视图与纠错依据可追溯 |

首期“完整页面样子”因此是可核验的结构、语义、状态与布局表达；在证据不足时输出诚实的部分结果，而非保证任意页面都能被完整还原。
