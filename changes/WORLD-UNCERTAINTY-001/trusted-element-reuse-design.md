# 已验证元素信息跨版本复用：先参考，按依据沿用

日期：2026-10-23。Authority NONE。状态：Q19范围与采信条件Accepted A，所有者答“按推荐”。Q1-Q18已接受决定不重开。第一版错误后的实际操作及后续影响Q20现亦Accepted A，见correction-impact-design.md。仅设计与文档，不实现、不运行产品/模型/设备，不冻结公共字段或新增Owner。

## 要改变的等待行为

同一个页面/元素后续再次出现时，不能只因World/Slice来源版本变化，就把过去已经核实的用途、含义全部遗忘并强制等待慢模型重新解释。目标是先让真实消费者拿到可用认识，只有新增、变化、歧义或本次消费所缺的信息才需要补证；不是每一轮都必须后台再跑一次同样的模型。

“高置信度”在这里首先指有可追溯、已被接纳且未被推翻的验证依据，不等于模型自报的一个高分。本稿不新增confidence阈值、次数投票、统一可信度Owner或保鲜时间常量。模型自信程度不能单独证明对象对应、当前存在或适用性。

## 推荐分两步，避免把参考和当前事实混在一起

1. **历史已验证认识可以先参考。** 当前实体/范围足以找到相关历史时，已有稳定语义可在消费者本次读取/咨询中立即提供，标明历史来源、适用范围及尚未本轮核实的部分。即使慢模型尚未返回，也不把它作为历史参考可见的前置。已知被纠正、来源失效或适用范围不符的旧判断，不能继续作为可信建议；查看原历史快照仍可保留其原样及纠正关系。
2. **本轮对应充分时，稳定语义可以直接沿用。** 本轮已有被接纳的快速观察、结构或连续性依据，足以由World判断仍是对应页面/元素、相关适用条件兼容、没有未解决反证时，World可以利用既有稳定语义派生新的当前表达，不必等待慢语义模型重复说一遍。新World/Slice保留旧语义验证来源与本轮对应依据；原Slice不修改，consumer也不自行缓存旧view跨operation重放。

第二步并非要求每次用新慢模型重新证明同一语义。所需对应依据可以来自现有合法观察和既有持续事实，但是否充分由原Owner判断；无对应信息时仍能参考历史，不能直接宣称当前元素已确认。若当前快速观察本身已足够提供动态状态/位置，可按既有消费链使用，也不人为等待慢模型。

## 按信息内容决定能沿用什么

| 信息 | 可立即参考什么 | 纳入本轮事实时检查什么 |
|---|---|---|
| 控件用途、角色、参数含义等相对稳定语义 | 过去验证过的含义及来源 | 页面/元素对应、上下文/适用条件及是否有反证；不是仅同文字/同route |
| 名称、描述、所属关系、结构/布局 | 历史名称/归属/布局可作理解线索 | 这些也可能随语言、设备、页面版本或父上下文改变；只复用仍适用的部分，不能永久列为静态 |
| 开关状态、数值、可见性、enabled及当前位置 | 可以明确展示“此前观察到”，不当作现在 | 本次消费所需的现行依据或充分性；缺证据保持未知，不能因历史分数高自动继承 |
| 当前操作定位、binding及执行/完成判断 | 历史用于理解和定位候选，不直接获得操作资格 | 继续由World/Assurance/Effect等原Owner的当前消费链判断；不靠引用旧Slice或旧locator恢复执行资格 |

不必等整页所有元素都完成语义识别。单个元素或字段已满足复用条件时即可供对应读取使用；另一个无关区域仍未知，不应强制阻塞该项稳定语义。具体动作所需条件仍由原消费者决定，不能因可读语义先出就跳过动作所需依据。

## 具体例子

第一轮已核实蓝牙页面某控件的含义为“控制蓝牙启停”。第二轮进入同一上下文，快速观察足以把本轮控件与该已知对象对应起来，则World可沿用其用途，让Agent理解这是什么，不等慢模型重复解释。

第一轮“开”的状态不自动带入第二轮：第二轮快速依据若显示“关”，当前表达使用关；如果本轮状态未读到，则用途已知、当前状态未知可以同时存在。位置同理，旧控件坐标不因为用途复用就变成本轮可执行定位。

如果第二轮尚未确认对象对应，Agent可先读到“历史上这里有这样一个控件”的相关参考；不能把“本轮确定看到了同一控件”写成事实。语义本身、当前对应及动态状态是不同的已知/未知内容，不必被一个整页等待开关绑在一起。

## 发现变化或纠错后的处理

- 归属、对象对应、语义来源或相关适用条件被推翻时，World按Q17已定的依赖关系重判所有受影响的当前派生内容；可替换、标冲突或退为未知，不简单让最新模型版获胜。
- 独立、未受影响的语义继续使用；一个控件变化不应无依据地使整页已知含义全部作废，也不能因另一处高置信就忽略本处反证。
- 历史依据的置信与采集时间不被“复用到新revision”刷新。新revision表示此时作了什么采信/派生决定，不伪装成重新观察过。
- 需要补证时沿既有Control/Perception链，只处理确有需要的部分；不新增每轮后台全量识别任务、Agent咨询或重置预算。任何实际咨询中的动态内容仍走正式Owner投影→AgentDecisionContext→decision输入，不放进只首次发送的能力目录。

## 与当前代码/契约的关系

- UiEntityModel.cs:23-61区分revision-local occurrence与有界持续LogicalItem；Continuity.cs及WorldModel.cs:979-1056以当前候选、支持/反证依据进行判别。它们提供“同一对象”与“本轮呈现”分开的基础，但不是已交付的通用历史语义复用策略；不为所有语义强制新铸LogicalItem或开tracking demand。
- WorldModel.cs:1318-1378的ResolveCurrent基于current occurrence派生候选；WorldModel.Semantics.cs:19-52按当前观察的capture/cycle/session/依据匹配。不能为了复用而把旧语义重新贴成新capture、绕过这些gate。复用须从World已接纳事实/来源及新对应关系派生，不把旧模型消息伪装成新观察再次投递。
- UiHierarchyOccurrenceStrategy.cs:40-85对特定不改变当前结构的输入保留previous occurrences及原basis；它同时阻止退休capture重建当前页面。这是特定realization的延续路径，不证明已经支持跨导航、多轮、按字段的稳定语义复用，也不将其泛化为“旧坐标永远有效”。
- ADR-0010把freshness作为消费相关的Assurance判断；ADR-0011要求Owner从current即时派生消费视图。新快照可保留旧证据而不必所有依据都重新采集，但它们对这次消费是否充分仍按原规则判定。新语义复用不放宽旧Slice的currency，也不制造consumer缓存或平行truth。

## 业界参考及限制

RFC5861的stale-while-revalidate展示先返回已有表示、隐藏复核延迟的思路；RFC9111要求复用与对应请求/表示及验证条件匹配。官方原意、Informational定位和迁移限制见trusted-reuse-primary-sources.md。

这里只作有限类比，不把HTTP缓存当世界事实模型，不引入该RFC的TTL，也不要求所有历史语义都重新跑后台模型。当前UI状态、身份、locator和执行资格不会由缓存类比获得证明。

## 首期拟验收：8类新增场景

以下是接在原18类提纲后的复用专项，不替换已定多轮/纠错验收；需按用户要求在实现时展开详细用例或仿真。

| ID | 可控情形 | 应有结果 |
|---|---|---|
| RU01 | 有相关历史稳定语义，慢模型未返回或保持挂起 | Agent/页面读取可先得到带来源的历史参考；当前未证字段仍未知，不将慢模型完成作为该读取前置 |
| RU02 | 本轮对应充分且无反证，稳定语义没有变化 | 新World/Slice可沿用该语义并关联旧验证/本轮对应来源；不为相同含义强制重复慢模型调用 |
| RU03 | 历史高置信“开”，本轮是“关”或未取到状态 | 有依据用本轮关；无依据为未知，不从旧状态补默认值；用途仍可独立复用 |
| RU04 | 控件位置改变、不可见或当前无候选 | 历史含义不使旧坐标/locator成为当前可执行目标；相应当前缺口显式保留 |
| RU05 | 页面同route/同文字，但设备、父上下文或候选对象不匹配/有歧义 | 不把旧语义确认为该本轮对象的事实，不强制合并身份；历史参考适用范围明确 |
| RU06 | 旧语义已经被撤销，或后来纠错推翻已复用的共同依据 | 已知无效内容不继续作为可信复用项；所有实际依赖者重判，未受影响项保留，旧快照不回写 |
| RU07 | 一个局部需补证，另一个已满足复用；后台结果乱序/重复或与旧语义矛盾 | 不无依据整页等待；相关结果按capture/来源与冲突规则处理，不能因到达晚或分数高覆盖当前 |
| RU08 | 仅新World修订/新模型配置出现，既有相应语义/依赖未变 | 保留处理来源，不伪造新观察时间或现场变化，不重建旧Slice；无关修订不强迫重新识别 |

速度收益要通过可控“慢模型不返回”与实际输入/投影可用顺序、调用记录证明，不预先编造毫秒目标。不能用外部自造模型直接填入预期结果，再宣称正式World及真实Agent链已通过。

## 已接受规则与新的讨论前沿

Q19 Accepted A：历史已验证稳定信息先作为有来源参考提供；当前对应依据充分时由World沿用稳定语义，免等重复慢模型；动态状态/位置/存在及操作条件按本次依据与原Owner规则判断，纠错沿依赖传播。用户提出的是“参考不用等”，本稿不将其扩成旧locator直接执行。

Q20 Accepted A：第一版有误时，除纠正当前语义，还要追查错误认识驱动过的操作及后续判断。发现即处理受影响链路、按动作阶段核实真实效果、结束再做范围核对；没有通用自动回滚保证，也不能让同一错误来源的复用检查自证正确。仅历史记录未被消费时关联更正即可；已被使用则按实际依赖处理。详见correction-impact-design.md。

method：当前World/Continuity/occurrence/Host派生及ADR限定只读核对，一名Worker反例审阅并整理两份RFC官方资料；共享脏文件及负责文档先快照。

expected：减少重复识别与整页等待，历史参考和可被采信的当前语义均有合法路径；动态未知不伪装，旧快照不回写，Owner不增加。

actual：Q19/Q20已Accepted A，8类复用拟验收及错误影响处理边界已记录；没有新增产品裁决，工程细化/验证仍待完成。当前不声称已有性能收益、通用复用实现或真实Agent输入通过，未运行产品/模型/设备。

evidence：本文代码/ADR锚点、trusted-reuse-primary-sources.md、version-layer-design.md、model-interface-review.md；evidence/trusted-reuse-entry.json与evidence/trusted-reuse-verification.json。
